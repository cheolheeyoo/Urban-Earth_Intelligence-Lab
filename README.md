# UEI Lab 홈페이지

첨부된 사이트 프레임을 유지하여 부산대학교 도시지구지능연구실의 실제 콘텐츠로 채운 버전입니다. **한국어가 기본 언어이며 English를 선택할 수 있습니다.**

## 반영한 내용

- 한국어 기본과 English 선택, 흰 배경의 기존 프레임을 유지했습니다. 메인 배경은 도시 비중이 높은 첨부 이미지 `image(4).png`로 교체했습니다. 배경의 도시 지역이 더 잘 보이도록 PC·모바일에서 이미지 왼쪽을 기준으로 배치했습니다.
- 기존 UEI 로고의 심볼을 헤더에 배치했습니다. `assets/img/brand/uei-lab-logo.png`는 원본 이미지이며, `assets/js/app.js`의 SVG 뷰포트로 심볼 부분만 표시합니다.
- 메인 영문 연구실 이름 위에 첨부된 부산대학교 로고(`signature04.png`)를 배치했습니다. 원본 비율과 투명 배경을 유지합니다.
- 모바일·태블릿 헤더 최상단에 **한국어 / ENG** 전환 줄을 별도로 두었습니다. 메뉴를 열지 않고 전환할 수 있으며 현재 언어가 강조됩니다.
- 헤더 이름은 `Urban Earth Intelligence (UEI) Lab`, 한글 부제는 `부산대학교 도시지구지능연구실`입니다.
- 메인 영문명·굵은 한글 제목·소개 문구와 연구실 소개를 수정했습니다. 메인 소속 표기는 **부산대학교 스마트시티전공·도시공학과**입니다.
- 하단 영상 설명은 **자연색 합성 위성영상 / 위성 지표면온도 / 위성 기반 식생지수**로 바꾸고 영문에도 위성 관측임을 명시했습니다.
- 메인 화면 최근 논문 목록의 공동제1저자 태그를 제거했습니다.
- 첫 화면과 연구실 소개 사이에 첨부된 부산 영상 3장(True color image, LST, NDVI)을 가로 전체 너비로 배치했습니다. 마우스를 올리면 해당 영상만 살짝 흐려지며 중앙에 설명과 얇은 프레임이 나타납니다. 모바일에서는 이미지를 터치하여 설명을 열고 닫을 수 있습니다. 키보드 Tab으로 이동하고 Enter·Space로 전환하며, Escape로 닫을 수 있습니다. 화면이 좁을 때는 세로로 배치하고, 동작 줄이기 설정을 따릅니다.
- 연구 4개 분야의 한글·영문 내용과 동일한 스타일의 일러스트를 추가했습니다.
- 지도교수 소속은 **부산대학교 스마트시티전공 (도시공학과 대학원)**으로 반영했습니다.
- 학력, 경력, **국제저널 편집위원**을 순서대로 세로 배치했습니다. 경력과 학술지 IF는 사용자 제공 값을 반영했습니다.
- 학부생 인턴 3명의 기본 카드는 유지했습니다.
- 논문은 2020년부터 연도별로, 2019년까지는 **2020 이전 / Before 2020**으로 통합했습니다. 연도별 편수 표시는 제거했습니다.
- 논문 46편·도서 챕터 4편과 실제 논문 첫 페이지 이미지 16장을 유지했습니다.
- **주요 대표논문 / Key publications**을 논문 페이지 상단의 하나의 카탈로그로 통합했습니다. 국내학술지와 MDPI 논문을 제외한 국제학술지 8편을 연도 구분 없이 표시합니다. 기존 국제 대표논문 5편에 사용자가 첨부한 2022년 JAG 논문과 2019·2018년 ISPRS JPRS 논문을 추가했습니다. 첨부 논문은 기존 전체 목록과 DOI로 대조하여 중복 없이 대표논문으로 지정했습니다. 연도·유형 필터는 아래 전체 목록에만 적용됩니다. 전체 목록에는 국내학술지와 MDPI 논문도 유지됩니다.
- 유철희 교수의 역할을 사용자 제공 정보에 따라 별도로 표시했습니다. `paper-01`, `paper-12`, `paper-28`, `paper-36`은 **공동제1저자 / Co-first author**, `paper-22`는 **교신저자 / Corresponding author**입니다. 대표논문 카드에는 역할 태그를 표시하지 않으며, 카드를 클릭한 상세 화면에서 저자 역할을 확인할 수 있습니다. 연도별 전체 논문 목록의 저자 역할 표기는 유지합니다.
- 저자는 `Yoo, Cheolhee, Yuhan Zhou, and Qihao Weng` 형식으로 통일했습니다. 첫 저자는 성, 이름 순서이며, 이후 저자는 이름 성 순서입니다. 최근 논문의 약자·생략된 저자 목록은 출판사·기관·저자 연구실 자료로 보완했습니다. 원문에서 사용하는 중간 이름의 약자와 `T. C. Chakraborty` 등은 임의로 확장하지 않았습니다.
- 주소는 **부산대학교 건설관(401동) 704호**로 수정하고 우편주소와 연구실 지원 안내를 반영했습니다.
- 연락처 주소 위에 첨부된 UEI 로고 전체를 크게 배치했습니다. 지도는 컬러 위성영상과 지명·도로명이 결합된 하이브리드 화면으로 열리며, 로고와 지도 상단을 맞췄습니다.

## 바로 확인하기

압축을 푼 뒤 `index.html`을 브라우저에서 여세요. 별도 설치나 빌드가 필요 없습니다.

- 처음 열면 한국어로 표시됩니다.
- 상단의 `한국어 / English`에서 언어를 전환합니다. 모바일에서는 헤더 맨 위의 `한국어 / ENG` 전환 줄이 항상 표시됩니다.
- 선택한 언어는 브라우저에 저장됩니다.
- `index.html?lang=ko`는 한국어, `index.html?lang=en`은 영문으로 바로 열립니다.
- 언어를 바꾸고 다른 메뉴로 이동해도 선택한 언어가 유지됩니다.
- 논문 연도 선택·유형 필터·이미지 확대 기능을 사용할 수 있습니다.
- DOI·PDF·지도와 Google Fonts는 인터넷 연결을 사용합니다. 글꼴을 불러오지 못하면 시스템 글꼴로 표시합니다.

## 학부생 인턴 3명 수정하기

`data/people.js`의 `groups[0].members`에 기본 카드 3개가 있습니다.

```javascript
{
  "name": { "ko": "실제 이름", "en": "English Name" },
  "role": { "ko": "학부생 인턴", "en": "Undergraduate intern" },
  "placeholder": false,
  "photo": "assets/img/people/student-01.jpg",
  "email": "",
  "interests": { "ko": "관심 연구 분야", "en": "Research interests" }
}
```

1. `name`에 한글·영문 이름을 입력하세요.
2. 사진은 `assets/img/people/`에 넣고 `photo`에 경로를 적으세요. 세로 4:5 비율이 잘 맞습니다.
3. `placeholder`를 `false`로 바꾸고 `placeholderLabel` 항목을 삭제하세요.
4. `email`, `interests`를 입력하세요. 빈 문자열 `""`로 두면 화면에 나타나지 않습니다.

현재 기본 이름은 **학부생 인턴 01, 02, 03**입니다. 실제 학생 이름·이메일·사진·연구 분야를 임의로 만들지 않았습니다.

### 논문 추가

`data/publications.js`의 배열에 다음 형태로 추가하세요. 아래 값은 설명용 예시이며 실제 논문 정보로 바꿔야 합니다.

```javascript
{
  "id": "paper-unique-id",
  "year": 2027,
  "type": "journal",
  "title": "실제 논문 제목",
  "authors": "Yoo, Cheolhee, Yuhan Zhou, and Qihao Weng",
  "venue": "실제 학술지 이름",
  "publisher": "실제 출판사 이름",
  "doi": "10.xxxx/actual-doi",
  "url": "",
  "pdf": "",
  "featured": true,
  "thumb": "assets/img/papers/your-paper.webp",
  "license": "",
  "licenseUrl": ""
}
```

- `type`: `journal`, `conference`, `book`, `other` 중 하나입니다.
- `year`는 실제 발행 연도 숫자입니다. 새 연도는 자동으로 표시됩니다. 2020년 미만은 화면에서만 `2020 이전`으로 묶이며, 각 논문의 실제 연도는 유지됩니다.
- `publications.html#before-2020`으로 묶음에 바로 접근할 수 있습니다. 기존 `#2019`, `#2018` 링크도 해당 묶음으로 연결됩니다.
- `featured: true`와 `thumb`가 있으면 페이지 상단의 주요 대표논문 카탈로그에 나타납니다. `publisher`에 `MDPI`가 있거나 DOI가 `10.3390/`으로 시작하거나 URL이 `mdpi.com`인 논문은 카탈로그에서 제외됩니다. 전체 논문 목록에서는 제외되지 않습니다.
- 대표 이미지가 없거나 국내논문이면 `featured: false`로 두세요. 일반 논문 목록에는 표시됩니다.
- `pdf`는 공개 PDF 주소가 있을 때 입력합니다.
- 저자는 첫 저자만 `성, 이름`, 이후 저자는 `이름 성` 순서로 입력하고 마지막 저자 앞에 `and`를 씁니다. 위 예시는 표기법을 보여 주기 위한 것으로 새 논문의 실제 저자 정보로 바꿔야 합니다. 이름은 확인된 원문 철자와 저자 순서를 유지하세요. 한글·영문 사이트에서 동일한 서지 정보를 사용합니다.

PDF에서 첫 페이지 이미지를 만드는 기존 도구도 포함했습니다.

```bash
pip install pymupdf pillow
python tools/make_thumbnails.py your-paper.pdf
```

유철희 교수의 저자 역할은 해당 논문의 `labAuthorRole`에 `"co-first"`(공동제1저자) 또는 `"corresponding"`(교신저자)을 넣으면 한·영으로 자동 표시됩니다. 역할이 없는 논문은 이 항목을 생략합니다. 이 값은 저자명·순서를 바꾸지 않습니다.

이미지의 원본 내용을 유지하고, 해당 논문의 출처·라이선스를 기재하세요. 현재 들어 있는 첫 페이지 이미지의 출처는 `assets/img/papers/sources.json`에 정리되어 있으며, 확대 화면에도 라이선스 링크가 표시됩니다.

### 소식 추가

`data/news.js`에서 `date`, `category`, `title`, `body`를 입력하세요. 날짜는 정확히 확인한 범위에 따라 `2026`, `2026-03`, `2026-05-11`처럼 사용할 수 있습니다. 연·월만 입력하면 확인되지 않은 날짜를 표시하지 않습니다.

## GitHub Pages에 올리기

1. 압축 파일 **안의 파일과 폴더**를 저장소의 최상위에 올리세요. ZIP 자체를 올리는 것이 아닙니다. `index.html`, `assets`, `data`가 저장소에서 바로 보여야 합니다.
2. `.nojekyll` 파일도 포함하세요.
3. `Settings → Pages → Build and deployment`에서 **Deploy from a branch**를 선택하세요.
4. **main / (root)**를 선택하고 저장하세요.
5. 배포 완료 후 같은 화면의 **Visit site**에서 확인하세요.

기존 사이트를 교체할 때는 현재 파일을 백업한 뒤 교체하면 됩니다. 기존 `CNAME`이 있다면 유지하세요. 이 패키지는 도메인 설정을 자동으로 변경하지 않습니다.

기존 `urbanearthintelligence.com`을 같은 저장소에서 사용 중이라면 기존 도메인 설정을 유지합니다. 새 저장소에 연결하는 경우 GitHub Pages의 Custom domain 설정과 DNS를 연결해야 합니다.

- [GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)
- [게시 브랜치 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- [도메인 연결](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)
